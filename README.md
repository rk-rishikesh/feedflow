# RIZZ NETWORK 🚀

**Rizz Network** is a multi-agent intelligence pipeline that transforms "raw noise" into "high-signal content." By orchestrating specialized AI agents, it reason through YouTube transcripts, GitHub repositories, complex PDFs, and web articles to architect content with **peak Rizz**.

## 🧠 How it Works

1. **Feed the Beast**: Drop your links (YouTube, GitHub, Web) or upload documents.
2. **Orchestration**: Our system uses an Orchestrator Agent to synthesize these sources into a Unified Knowledge Context.
3. **Pick Your Channel**: Choose your target output — X (Twitter) threads, LinkedIn articles, long-form blog posts, or structured digests.
4. **Refine with Rizz**: Give specific instructions to our agents to perfect your POV and editorial style.

## 🤖 Multi-Agent Architecture

The core of Rizz Network is a sophisticated orchestration layer involving multiple specialized agents. 

- **Orchestrator Agent**: The master aggregator and project architect.
- **Channel Agents**: Domain-specific writers for LinkedIn, X, and Articles.
- **Refinement Agent**: Handles iterative feedback and stylistic updates.
- **Visual Agent**: Generates context-aware imagery for your content.

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org) (App Router)
- **AI Models**: Google Gemini 2.0 Flash (Orchestration & Content)
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion
- **Scrapers**: Custom-built YouTube & GitHub intelligence layers

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Set up your environment variables:

```bash
# .env
GEMINI_API_KEY=your_key_here
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start architecting high-velocity content.
